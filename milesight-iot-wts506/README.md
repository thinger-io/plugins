# WTS506 - Weather Station

The WTS Series are an all-in-one LoRaWAN® weather monitoring system for various atmospheric conditions, such as temperature, humidity, wind speed, wind direction, barometric pressure and rainfall. Consisting of three main parts—WTS Sensors, WTS Hub, and solar panel—the IoT Weather Station is designed to withstand the most challenging weather conditions and is easy to install in different scenarios to be widely used in meteorology, smart agriculture, smart building, and other applications.

## Features

- Integrated with multiple sensors: temperature, humidity, barometric pressure, wind speed, wind direction, and rainfall
- LoRaWAN® connectivity for long-range wireless communication
- Solar-powered design for autonomous operation
- Robust construction suitable for harsh outdoor environments
- Easy installation and deployment
- Compatible with Milesight IoT Cloud for data management
- All-in-one weather monitoring solution

## Use Cases

- **Meteorology**: Professional weather monitoring and forecasting
- **Smart Agriculture**: Crop management and irrigation optimization based on real-time weather data
- **Smart Building**: Environmental monitoring for building management systems
- **Environmental Monitoring**: Long-term atmospheric data collection

## Thinger.io Integration

The WTS506 integrates with Thinger.io through LoRaWAN connectivity, enabling real-time weather data visualization, storage, and analysis on the platform.

## Requirements

A LoRaWAN server is required to communicate the WTS506 into Thinger.io. Available options include:

- [The Things Stack](https://www.thethingsindustries.com/stack/)
- [LORIOT](https://loriot.io/)
- [ChirpStack](https://www.chirpstack.io/)

Alongside, the corresponding plugin for the selected LoRaWAN server needs to be installed in your Thinger.io instance.

## Get Started

### Installation

Look for the plugin in the [Thinger.io Plugin Store](https://marketplace.thinger.io/) and install it in your Thinger.io instance. Once the plugin is installed a new Product will be created for this device.

### Configuration

The Product is already preconfigured, check that the auto provision prefix matches the one selected in your LoRaWAN server plugin in Thinger.io, or change it to your desire.

### Usage

Start sending uplinks for autoprovisioning devices and buckets. This product also provides a predefined dashboard for monitoring all atmospheric parameters including temperature, humidity, wind speed, wind direction, barometric pressure, and rainfall data.
